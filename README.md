# THE BLIND SPOT — PHP2Shell / 空白の30日間

PHPの脆弱性が、受注・製造・物流を通して企業と社会にどう関わるかを考える、日本語の3D教育プロトタイプです。中央のPHP基盤と5つの業務拠点を抽象的な立体で表現しています。

## 2つの体験

**空白の30日間**：架空の部品メーカーの社長として、更新、初動隔離、証拠保全、第一報、要求と復旧に関する5つの判断を行います。DAY 0 / 1 / 3 / 7 / 14 / 30 の時間軸で、その時点で見えていた情報を振り返れます。

**この先180日**：AIなどの支援による発見の増加を入口に、更新を続ける体制を考えます。発見の流れ3種類、更新周期7・30・90日、1回の処理量1・2・3課題を変更し、同じ架空の課題が届く2つの対応計画を比較できます。更新待ち、累積の未対応課題×日、計画更新回数と3Dの色が連動します。

180日モードは将来を考えるための単純化したモデルです。数値は架空で、脆弱性の件数、攻撃確率、倒産、半年での収束を予測するものではありません。課題の難しさや優先度は同じと仮定しています。

## 起動と検証

アプリ本体はビルド不要の静的ファイルです。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

ブラウザで `http://127.0.0.1:4173/` を開きます。ES Modulesを使うため、`file://` からの直接起動には対応しません。

```sh
npm test
```

Node.js標準のテストランナーで、30日間の全243経路と、180日間の全27設定を検証します。履歴に未来の判断が混入しないこと、事前更新と事後更新の違い、課題数の保存と累積計算などを確認しています。

## 事実と演習の境界

脆弱性の識別子・公開日・修正版は2026年10月23日時点のPHP公式・JPCERT/CCの公開資料に基づきます。設定例はPHP 8.3.35 / Apache mod_php、修正版は8.3.36です。実際に脆弱なPHPや攻撃コードはインストール・実行しません。

企業、接続、時間経過、被害、指標、対策効果は学習用の仮定です。30日間の赤は権限・分離不足を追加仮定した侵害経路、橙は業務への影響です。180日間の橙は対応負荷を表します。参考事件をPHP2Shellによる事件として扱っていません。事実の根拠と教材上の解釈は [SOURCES.md](SOURCES.md) に記載しています。

回答・進捗はこのブラウザのlocalStorageに保存し、外部送信しません。認証・バックエンドはありません。Google Fontsの読み込み時には同サービスへの通信が発生し、未接続時はシステム書体を使います。

## ソース構成

| ファイル | 役割 |
| --- | --- |
| `dist/index.html`, `dist/style.css` | 画面とレスポンシブデザイン |
| `dist/app.js` | 演習、モード切替、時間軸、保存、出典 |
| `dist/scene.js` | PHP基盤の3D、経路・状態表示、WebGL代替表示 |
| `dist/scenario.js` | 30日間の分岐・履歴再生・学習指標 |
| `dist/future.js`, `dist/future.css` | 180日間の比較モデルとUI |
| `dist/references.js` | 根拠資料とPHPバージョン情報 |
| `dist/vendor/` | Three.js 0.180.0、OrbitControls、MITライセンス |
| `tests/` | Node.js標準テスト |
| `.github/workflows/pages.yml` | GitHub Pagesへの静的配信 |

`main`へのpushでGitHub Actionsが`dist/`をPagesへ配信します。Three.jsは同梱済みで実行時にCDNから取得しません。WebGLが使えない場合は拠点一覧に切り替わります。
