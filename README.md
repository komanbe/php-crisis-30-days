# THE BLIND SPOT — PHPから始まる、あなたの物語

PHPの脆弱性が、受注・製造・配送とその先の暮らしにどう関わるかを体験する、日本語の3D分岐ストーリーです。

## 体験の流れ

映画の冒頭をイメージしたタイトル画面で「開始する」を押し、2つの物語から1つを選びます。会話は「次へ」で進み、重要な場面だけ3回の二択が現れます。スライダーや比較設定の操作は不要です。

- **その更新、明日でもいい？**：日用品を受発注する会社の社長として、PHPの更新、初動、関係者への説明を判断します。早めの更新と先送りでは、その後の会話と結末が変わります。
- **更新が、終わらない世界**：PHPの更新を終えた先の180日間。継続する対応を、予定・担当・連絡の仕組みで支えられるかを考えます。

最後に、情シス・受注・工場・配送・調達・商品を待つ人の6人を振り返ります。誰に、どんな負担が届いたか、どの日常を守れたかを表示します。復旧後も、それまでに生じた負担を消さずに扱います。

PHPは「Webの受付を裏で動かす仕組み」として物語の中で説明。教材の環境はPHP 8.3.35 / Apache mod_php、8.3系の修正版は8.3.36です。詳細と出典はメニューから読めます。

## 起動と検証

ビルド不要の静的サイトです。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
npm test
```

Node.js標準のテストで、両ストーリーの全分岐、入力検証、事前更新による展開の違い、最後の6人への影響を確認します。従来の30日間モデル・180日間モデルの検証も維持しています。

## 事実とフィクション

PHPの識別子・公開日・修正版は2026年10月23日時点のPHP公式等の公開資料に基づきます。企業・人物・会話・時間経過・分岐・結末は学習用の架空設定です。被害規模や対策効果、将来の脆弱性件数を予測するものではありません。

橙色は業務上の影響または更新作業の負担です。取引関係による業務の波及と、他社のシステムへの侵入は異なります。実際に脆弱なPHPや攻撃コードは実行しません。参考事件をPHP2Shellによる事件として扱っていません。資料と教材上の解釈は [SOURCES.md](SOURCES.md) を参照してください。

回答と進捗はブラウザのlocalStorageに保存し、外部送信しません。途中で離れた場合は、タイトルから同じ物語を選ぶと続きから体験できます。認証・バックエンド・外部フォント読み込みはありません。

## 主なファイル

| ファイル | 役割 |
| --- | --- |
| `dist/index.html`, `dist/story.css` | 映画風の入口、会話、二択、エピローグの画面 |
| `dist/story.js` | 画面遷移、進捗保存、出典、3Dとの連動 |
| `dist/story-data.js` | 2つの物語、分岐、人物ごとの結末 |
| `dist/scene.js` | PHP基盤と6人の3D、物語のカメラ、WebGL代替表示 |
| `dist/characters.js` | 架空の登場人物 |
| `dist/references.js` | 参考資料・PHP情報 |
| `dist/scenario.js`, `dist/future.js` | 前版の学習モデル（現行の入口からは使用しない） |
| `dist/vendor/` | 同梱Three.js、OrbitControls、MITライセンス |
| `tests/` | 分岐と学習モデルのテスト |

`main`へのpushでGitHub Actionsが`dist/`をGitHub Pagesへ配信します。WebGLが使えない環境でも、物語と拠点の代替表示で体験できます。
